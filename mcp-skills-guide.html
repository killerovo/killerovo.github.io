1. MCP 是什么？

一句话解释

MCP（Model Context Protocol，模型上下文协议）是 Anthropic 于 2024 年 11 月开源的开放协议，用于标准化 AI 模型与外部工具/数据源之间的通信。

通俗理解

想象一下：AI 模型就像一个聪明的大脑，但它「困」在对话框里，不能直接读写你的文件、访问数据库、调 GitHub API。MCP 就是给这个大脑安装 「USB 接口」——插上什么设备，就能用什么功能。

为什么要 MCP？

以前，N 个 AI 模型 × M 个工具，需要 N×M 个适配器。MCP 把这个变成了一个标准接口：所有模型只要实现了 MCP 客户端，就能调所有实现了 MCP 协议的工具。

指标数据（2026 年）
月 SDK 下载量9,700 万次
活跃 MCP Server10,000+
支持方OpenAI、Google、Microsoft、AWS
治理已移交 Linux Foundation 旗下 Agentic AI Foundation

常见 MCP Server 举例

MCP Server能做什么
文件系统 MCP让 AI 读取、编辑、创建本地文件
GitHub MCP让 AI 管理仓库、创建 Issue/PR、查看代码
数据库 MCP（PostgreSQL / MySQL）让 AI 查询数据库、分析表结构
飞书/钉钉 MCP让 AI 收发消息、操作文档
浏览器 MCP（Puppeteer）让 AI 打开网页、截图、抓取数据

2. Skills 是什么？

一句话解释

Skills（技能）是 Claude Code 提供的模块化能力扩展机制。本质是 Markdown 文件（SKILL.md），将专业知识和工作流固化为 AI 可自动加载执行的能力包。

通俗理解

如果 MCP 是给 AI 接外部设备的 USB 接口，那 Skill 就是给 AI 写的「操作手册」。比如你想让 AI 按你们团队的代码风格写代码，你不需要每次都啰嗦一遍——写一个 Skill 文件，AI 会自动加载并按规范执行。

Skills 的核心特征

特征说明
模块化封装把知识、步骤、规范固化为独立 Skill
自动触发Claude 根据上下文自动发现并调用合适 Skill
轻量只需 Markdown，不需要写代码
渐进式加载初始只占 ~400 tokens，按需展开，不像 MCP 一次性 ~8,000 tokens
可组合多个 Skill 可以串成完整工作流

Skills 能做什么？

场景Skill 示例
编码规范强制执行团队命名约定、文件结构、错误处理模式
测试生成自动按项目测试框架生成单测、Mock 策略
Git 工作流规范化 commit message、分支命名、PR 模板
代码审查按团队 checklist 逐项检查质量、安全、性能
DevOps 部署固化 Docker 构建、K8s 部署、CI/CD 流程

3. MCP vs Skills：核心区别

MCP 是「厨房系统」——锅碗瓢盆灶台通风。Skills 是「菜谱」——宫保鸡丁怎么做、火候多少、先放什么后放什么。

MCP 解决「模型能用什么工具」，Skills 解决「模型该怎么用这些工具」。

维度MCPSkill
本质开放协议 / 通信标准能力封装 / 操作手册
形式服务端程序（需写代码）Markdown 文件（写文档即可）
技术难度高（需写 Server + 配认证）低（写 Markdown）
Token 消耗~8,000 tokens（加载所有工具定义）~400 tokens（渐进式按需加载）
可组合性弱（每个工具独立）强（可串成工作流）
适用场景持久连接、复杂认证、企业集成知识固化、工作流规范、代码风格

两者不是替代关系，是协作关系。 比如你可以用一个 GitHub MCP Server 让 AI 访问仓库，再用一个 "PR Review Skill" 告诉 AI 按什么标准审查代码。

6. 怎么安装和使用？

6.1 安装 MCP Server

以 文件系统 MCP 为例（最基础的，10 分钟就能跑通）：

Step 1： 在 Claude Code 设置中注册 MCP Server。编辑 ~/.claude/.mcp.json（Windows 为 用户目录/.claude/.mcp.json）：

{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@anthropic-ai/mcp-server-filesystem", "/path/to/allowed/dir"]
    }
  }
}

Step 2： 重启 Claude Code，MCP Server 自动启动。现在 AI 就能直接读写你指定的目录了。

更多 MCP Server：

  • GitHub MCP：npx -y @anthropic-ai/mcp-server-github
  • PostgreSQL MCP：npx -y @anthropic-ai/mcp-server-postgres
  • 浏览器 MCP：npx -y @anthropic-ai/mcp-server-puppeteer
  • 去 mcpmarket.com 搜更多

6.2 安装 Skills

方式一：从 Skill 市场安装（最简单）

在 Claude Code 里直接运行：

npx skills add <技能名> -y

比如：

# 安装 find-skills 搜索引擎（累计安装 579K+）
npx skills add find-skills -y

# 安装 caveman 压缩 token
npx skills add caveman -y

# 安装 Anthropic 官方 skill-creator
npx skills add skill-creator -y

方式二：从 skillhub.cn 浏览安装

  1. 打开 skillhub.cn
  2. 搜索想要的技能类型，比如「测试」「部署」
  3. 复制安装命令，到 Claude Code 里运行

方式三：自己写 Skill（非常容易）

在项目目录新建 .claude/skills/my-skill/SKILL.md：

---
name: my-coding-standard
description: 强制执行团队的 Python 编码规范
---

# Python 编码规范

## 命名规则
- 类名用 PascalCase
- 函数和变量用 snake_case
- 常量用 UPPER_SNAKE_CASE

## 代码风格
- 每行不超过 100 字符
- 函数不超过 50 行
- 使用 type hints

## 错误处理
- 不裸捕 Exception
- 自定义异常类继承自项目基类

保存后 Claude Code 会自动加载，之后写代码时会自动遵循这些规范。

6.3 在聊天中切换和查看

# 查看当前已加载的 Skills
/skills

# 临时禁用某个 Skill
/skills disable my-coding-standard

# 启用
/skills enable my-coding-standard

    npx skills add find-skills -y -g

  2. 再装 skill-creator——把你们团队的规范变成 Skill：

    npx skills add skill-creator -y -g

  3. 然后去逛市场：

    • mcpmarket.com — 看全球热度榜
    • skillhub.cn — 搜中文本土化技能

总结

MCP = 给 AI 接工具的 USB 接口（协议层，需要写代码）
Skills = 给 AI 写的操作手册（应用层，Markdown 即可）

两者的关系不是替代，是协作。MCP 让 AI 能连接外部世界，Skills 教 AI 在每个场景中怎么做才是对的。

入门路径：先逛 mcpmarket 和 skillhub.cn 看看别人做了什么，再安装几个热门的试试，最后把你自己团队的规范写成 Skill。
