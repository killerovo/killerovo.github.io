MCP 是什么？

一句话解释

MCP（Model Context Protocol，模型上下文协议）是 Anthropic 于 2024 年 11 月开源的开放协议。它定义了一套统一的标准，让 AI 模型可以连接和使用外部工具与数据源——就像 USB 接口统一了电脑和外部设备的连接方式。

通俗理解

想象一下：AI 模型就像一个非常聪明的大脑，但它"困"在对话框里——不能直接读写你的文件、不能访问数据库、不能调 GitHub API、不能操作浏览器。

MCP 就是给这个大脑装上标准化的接口。就像你电脑的 USB-C 口，插上 U 盘就能读文件，插上显示器就能投屏，插上充电器就能供电——MCP 也是一样，接上什么 Server，AI 就能多一种能力。

为什么需要 MCP？

在 MCP 出现之前，情况是这样的：有 N 种 AI 模型，有 M 种外部工具。如果想让每一种 AI 都能用每一种工具，需要写 N × M 个适配器。每新增一个工具，所有 AI 模型都要重写集成代码。

MCP 把这个模型变成了一对接：所有 AI 模型只需要实现 MCP 客户端，就能调用所有实现了 MCP 协议的工具。就像一个标准插座——你不需要为每个电器专门拉一根电线。

Skills 是什么？

一句话解释

Skills（技能）是 Claude Code 提供的模块化能力扩展机制。本质是一个 Markdown 文件（SKILL.md），将特定领域的知识、流程、规范固化为 AI 可按需加载的"操作手册"。

通俗理解

如果 MCP 是给 AI 接工具的接口（硬件层），那 Skills 就是教 AI 怎么做的指南（软件层）。

举个例子：你想要 AI 按你团队的代码风格写 Python 代码。没有 Skills 的时候，你每次都要啰嗦一遍："类名用 PascalCase，函数用 snake_case，每行不超过 100 字符……"。有了 Skills，你把这些规则写成一个 Markdown 文件，放在项目里，Claude Code 会自动读取并遵循——你一句话都不用多说。

Skills 的核心特征

特征说明
模块化封装把知识、步骤、规范打包成独立的 Skill 文件

MCP vs Skills：核心区别

直观比喻：MCP 像厨房系统——锅碗瓢盆灶台通风。Skills 像菜谱——宫保鸡丁放什么料、火候多少、先放什么后放什么。有了厨房（MCP）你才能做菜，有了菜谱（Skills）你才知道怎么做才好吃。
对比维度MCPSkills
本质通信协议 / 开放标准知识封装 / 操作手册
物理形式服务端程序（需写代码）Markdown 文件（写文档即可）
技术门槛较高（需写 Server + 配置认证）极低（会用 Markdown 就行）
Token 开销~8,000 tokens（启动时加载所有工具定义）~400 tokens（渐进式按需加载）
可组合性一般（每个工具相对独立）强（可串联成完整工作流）
适用场景持久连接、复杂认证、企业级集成知识固化、工作流规范、编码风格
维护成本需维护服务器代码更新 Markdown 即可

两者并非替代关系，而是互补协作。你可以用 GitHub MCP Server 让 AI 访问你的仓库，再加载一个 "PR Review Skill" 告诉 AI：按什么标准审代码、重点检查哪些问题、回复模板是什么。

MCP 市场 — mcpmarket.com

mcpmarket.com 是目前全球最活跃的社区策展型 AI 工具与 Skills 目录，相当于AI 的"应用商店"。

提供什么？

  • 150+ Skills：覆盖编码、测试、部署、文档、安全等场景，大部分免费，少数付费 €5–15
  • 100+ MCP Server：持续更新，涵盖数据库、云服务、通讯工具、浏览器自动化等
  • 评分与排行：按安装量、用户评分排序，一眼看出哪些最受欢迎
  • 一键安装：每个工具都提供复制即用的安装命令
  • 多平台支持：Claude Code、ChatGPT、Codex、Cursor 等

排行榜怎么用？

打开 Leaderboard 页面，可以看到按安装量排行的 Skills 和 MCP 工具。新手建议从这里开始——排名靠前的通常质量最高、社区最活跃、文档最完善。

你也可以按分类筛选（前端、后端、DevOps、数据科学……），或者直接搜索关键词。

安装流程

  1. 在 mcpmarket 上找到想要的 Skill 或 MCP
  2. 复制页面上的安装命令
  3. 粘贴到 Claude Code 终端中回车执行
  4. 如果是 MCP Server，可能需要重启 Claude Code
  5. 如果是 Skill，安装后立即生效

怎么安装和使用？

安装 MCP Server

以最基础的文件系统 MCP为例，10 分钟就能跑通：

第一步：创建配置文件

在 Claude Code 的项目或用户配置目录中，创建（或编辑）.mcp.json 文件：

Windows 路径：C:\Users\你的用户名\.claude\.mcp.json

macOS / Linux 路径：~/.claude/.mcp.json

{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@anthropic-ai/mcp-server-filesystem",
        "/path/to/allowed/dir"
      ]
    }
  }
}

参数说明：

  • "filesystem"：给你这个 MCP Server 起的名字，随便取
  • "command": "npx"：用 npx 运行（不需要全局安装）
  • "/path/to/allowed/dir"：重要！改成你想让 AI 访问的目录绝对路径。AI 只能访问这个目录及其子目录，不能超出范围

第二步：重启 Claude Code

关掉 Claude Code 终端，重新打开。启动时你应该能在日志中看到 MCP Server 已连接的提示。现在你可以对 AI 说：

帮我把 /project/src/utils.js 里的所有 console.log 删掉

AI 会直接读写你的文件。

常用 MCP Server 安装命令速查：

MCP Server.mcp.json 中的 command 和 args

安装 Skills

方式一：从 Skill 市场一键安装（推荐新手）

在 Claude Code 终端里直接运行：

npx skills add 技能名 -y

具体例子：

# 安装 find-skills（技能搜索引擎，累计安装 579,000+）
npx skills add find-skills -y

# 安装 caveman（压缩 token 消耗，省钱提速）
npx skills add caveman -y

# 安装 Anthropic 官方的 skill-creator（用自然语言生成新 Skill）
npx skills add skill-creator -y
加 -g 可以全局安装：npx skills add 技能名 -y -g，这样所有项目都能用。
不加 -g 则只安装在当前项目。

方式二：从 skillhub.cn 浏览安装

  1. 打开 skillhub.cn
  2. 搜索你需要的技能类型，比如「React」「测试」「部署」
  3. 进入技能详情页，复制安装命令
  4. 到 Claude Code 终端里粘贴执行

方式三：自己写一个 Skill（零代码）

只需要创建一个 Markdown 文件。在你的项目根目录下：

mkdir -p .claude/skills/my-coding-standard

然后创建 .claude/skills/my-coding-standard/SKILL.md：

---
name: my-coding-standard
description: 强制执行团队的 Python 编码规范。当用户要求写 Python 代码时自动生效。
---

# Python 编码规范 v2.0

## 命名规则
- 类名用 PascalCase：`class UserManager`
- 函数和变量用 snake_case：`def get_user_by_id()`
- 常量用 UPPER_SNAKE_CASE：`MAX_RETRY_COUNT = 3`
- 私有方法以单下划线开头：`def _validate_input()`

## 代码风格
- 每行不超过 100 字符
- 每个函数不超过 50 行（超过需拆分）
- 所有公共函数必须有 type hints
- 用 f-string 而非 % 或 .format()

## 错误处理
- 禁止裸捕 Exception：必须指定具体异常类型
- 自定义异常类继承自项目基类 `AppError`
- 关键操作加 try/except 并记录日志

## 测试规范
- 每个模块对应一个 test_ 文件
- 用 pytest 框架
- 关键路径覆盖率不低于 80%
- Mock 外部依赖，不 Mock 内部逻辑

保存后，Claude Code 会自动检测并加载。之后你让它写 Python 代码时，不用多说一句话，它会自动按这些规范执行。

    不需要编程，打开记事本写 Markdown。参考上面的 Python 规范示例，换成你团队的规则就行。放到项目 .claude/skills/ 目录下，全组共享。

总结

MCP = 给 AI 接工具的接口（协议层，需写服务端代码）

Skills = 教 AI 怎么做的指南（应用层，写 Markdown 就行）

两者的关系不是替代，是协作。MCP 让 AI 能连接外部世界，Skills 教 AI 在每个场景中怎么做才是对的。

入门路径：先逛 mcpmarket 和 skillhub 看看别人做了什么 → 安装两三个热门的试试 → 把你团队的规范写成 Skill → 分享给团队一起用。
